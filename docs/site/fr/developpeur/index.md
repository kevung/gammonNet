## À qui s'adresse ce volet

À qui veut **lire, modifier ou porter** le code. Il suppose qu'on sait lire du C et du Python, et
il insiste sur ce qui **ne se voit pas** — les invariants qu'un refactor peut casser en silence.

C'est la partie la plus importante de ce volet : le code se lit, les invariants non.
