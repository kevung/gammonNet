seuil 1e-5 :

- 4 couches : **max|Δ| = 3,22e-6**, 14 réussis ; l'échec de `test_the_header_says_what_we_expect`

## 3. L'arrondi float16 — **mesure**

`bench/measure_fp16.py`, 20 000 positions, 9 617 222 enfants, 0-ply, 4 ouvriers (machine chargée :
aucun temps n'est relevé). Relevés : `i39-fp16-768_768_256_256_256.json`,
`i39-fp16-512_512_256_256.json`. Comparaison aux poids `c373141` (fiches du 2026-11-04 et du 2026-11-06) :

| | 768 `c373141` | 768 `ea604e7` | 4 c. `c373141` | 4 c. `ea604e7` |
|---|---|---|---|---|
| positions, équité moyenne | 2,8e-4 | **8,7e-4** | 7,0e-4 | 3,7e-4 |
| positions, équité max | 3,2e-3 | 4,2e-3 | 3,85e-3¹ | 3,2e-3 |
| enfants, équité moyenne | 2,7e-4 | 8,9e-4 | — | 3,8e-4 |
| enfants, équité max | 4,8e-2 | 1,7e-2 | **2,2e-1** | 5,1e-2 |
| désaccord de coup, 0-ply | 0,075 % [0,066 ; 0,084] | 0,079 % [0,070 ; 0,089] | 0,080 % [0,071 ; 0,090] | 0,088 % [0,079 ; 0,098] |
| perte par décision | 3,9e-8 | 4,1e-8 | 6,0e-8 | 8,8e-8 |

¹ Sorties, max (la fiche du 2026-11-04 ne donne pas l'équité max aux positions).

**Lecture.** L'écart moyen du 768×768 triple (2,8e-4 → 8,7e-4), et celui du 4 couches se divise
par deux. La perte en jeu reste de l'ordre de 1e-7 par décision, et les intervalles de désaccord se
chevauchent avec ceux de `c373141`. **L'enfant isolé à 0,22 du 4 couches `c373141` n'a pas
d'équivalent ici** (max 5,1e-2). Le maximum aux positions du 768×768 (4,2e-3) se rapproche du
plafond de 5e-3 de `test_the_packed_model_is_close_to_the_original_but_not_equal`, qui porte sur un
autre corpus : à surveiller si l'on adopte.

Le float16 ne bloque donc pas l'adoption. Son coût **sous recherche** (float16 − float32 au registre
T70, niveau `normal`) se mesure avec le reste, sur la machine dédiée.

## Reproduire

```bash
python tools/export_model.py --weights-commit ea604e7 --out models/candidate_ea604e7_768_768_256_256_256.bin
python tools/export_model.py --weights-commit ea604e7 --model cubeless_prob5_512_512_256_256.pt \
    --out models/candidate_ea604e7_512_512_256_256.bin
python tools/pack_fp16.py models/candidate_ea604e7_<n>.bin models/candidate_ea604e7_<n>.bin16
GN_MODEL_PT=build/weights/ea604e7/cubeless_prob5_<n>.pt GN_MODEL_BIN=models/candidate_ea604e7_<n>.bin \
    python -m pytest -q tests/test_infer.py
python tools/dump_reference.py --model models/candidate_ea604e7_<n>.bin --out build/ref_<n>.bin
python tools/dump_reference.py --model models/candidate_ea604e7_<n>.bin16 --out build/ref16_<n>.bin
GN_PARITY_MODEL=… GN_PARITY_MODEL16=… GN_PARITY_REFERENCE=… GN_PARITY_REFERENCE16=… node wasm/parity.mjs
python bench/measure_fp16.py --fp32 models/candidate_ea604e7_<n>.bin --fp16 models/candidate_ea604e7_<n>.bin16 \
    --positions 20000 --workers 4 --out docs/mesures/i39-fp16-<n>.json
```
