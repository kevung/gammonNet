# Modèle de retour — `DS-XX-retour.md`

À placer en tête du rapport rendu par la recherche approfondie, avant de le coller tel quel.

```
# DS-XX — <titre> — retour

**Date de la recherche** : AAAA-MM-JJ · **Outil** : Claude, recherche approfondie
**Prompt** : `docs/recherche/DS-XX-....md`, version du <date du fichier>

> **Ce que ce retour décide** : <une phrase, reprise du prompt>
> **Ce qu'il conclut** : <une phrase, écrite après lecture>
> **Ce qu'il ne tranche pas** : <une phrase>

---
<le rapport, collé tel quel>
```

## La relecture, avant de classer

Un retour de recherche approfondie **n'est pas une mesure de ce dépôt**. Trois vérifications
avant de s'en servir :

1. **Les étiquettes tiennent-elles ?** Toute ligne non étiquetée mesure/hypothèse est à traiter
   comme une hypothèse, quelle que soit sa formulation.
2. **Les licences sont-elles nommées ?** Une brique rapportée sans licence est inutilisable ; ce
   n'est pas une lacune vénielle, c'est le seul type d'erreur qu'on ne peut pas corriger après
   distribution.
3. **Les chiffres du folklore sont-ils signalés comme tels ?** Le backgammon a une littérature de
   forum abondante et souvent recopiée sans source. Un chiffre qui circule n'est pas un chiffre
   mesuré.

## L'après

Quand une vague est complète, `00-plan-depasser-gnubg.md` est amendé — et **lui seul** porte les
décisions. Un retour ne décide rien tout seul.
